## 🌟 Visão Geral

A versão **2.0.0** do **Painel SIGSSe** é uma rearquitetura completa da extensão de mascotes interativos e campanhas de saúde para o painel de chamadas de pacientes das Unidades Básicas de Saúde (UBS).

Esta entrega substitui integralmente a versão legada por uma **plataforma modular, orientada a conteúdo remoto, resiliente, segura e 100% testada em ambiente automatizado**.

---

## 🚀 Principais Funcionalidades

### 1. Plataforma de Autoria Declarativa de Conteúdo (`Content Authoring System`)
- Adição de novos mascotes, skins, mensagens e campanhas agendadas **sem necessidade de alterar código TypeScript da extensão**.
- Ferramenta estática de compilação `compile-content.js` para geração determinística do manifesto `content/manifest.json`.

### 2. Atualização Remota e Hot-Reload sem Page Reload
- Consumo de manifesto remoto hospedado no GitHub Raw (`https://raw.githubusercontent.com/...`).
- Atualização em tempo real via eventos `onUpdate` e armazenamento em `chrome.storage.local`.
- **Hot-Reload no DOM**: Atualização de gráficos e mensagens sem pressionar F5 ou reinstalar a extensão.

### 3. Suporte a Spritesheets PNG e Animações Frame-by-Frame
- Suporte híbrido no `MascotRenderer` para renderização de atlas PNG com deslocamento de quadros por `background-position`.
- Integração com a Máquina de Estados Finita (`MascotEngine` / FSM: `CELEBRATE`, `RUN`, `IDLE`).
- **Mecanismo de Fallback Gracioso**: Reversão automática para a skin SVG default em caso de imagem indisponível.

### 4. Painel Administrativo no Popup da Extensão
- Dashboard visual com métricas: Total de campanhas, ativas, futuras, expiradas e inativas.
- Pílulas de filtro por estado temporal (`Todas`, `Ativas`, `Futuras`, `Expiradas`, `Inativas`).
- Acordeão detalhado de mensagens por campanha.
- Botão `↻ Verificar Remoto` para sincronização manual sob demanda.

## 🛡️ Segurança e Garantias de Isolamento

1. **Princípio Read-Only no SIGSS**:
   - O adaptador DOM lê dados de chamadas em modo puramente passivo.
   - Nenhuma mutação ou gravação é realizada no sistema clínico do SIGSS.
2. **Anti-XSS e Sanitização Rígida**:
   - `SvgSanitizer` remove script, atributos de evento `on*` e URIs `javascript:`.
   - Textos de mensagens são inseridos exclusivamente via DOM seguro (`textContent`).
3. **Zero Credenciais**:
   - Nenhum segredo ou chave privada é empacotado no código ou documentação.
